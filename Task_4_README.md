# Task 4 - Sales Dashboard

## Overview
This project is part of the Data Analyst Internship Task 4: Dashboard Design.

An interactive sales dashboard was created using Microsoft Power BI to analyze business performance.

## Dataset
**Kevin Cookie Company Financial Analysis**

The dashboard uses sales and financial data containing fields such as Date, Country, Product, Units Sold, Revenue, Cost, and Profit.

## Key Dashboard Features
- Total Revenue KPI
- Total Profit KPI
- Revenue by Country
- Revenue by Year
- Revenue by Date
- Country slicer for interactive filtering

## Key Results
- Total Revenue: **5M**
- Total Profit: **2.76M**

## Tools Used
- Microsoft Power BI Desktop
- Microsoft Excel
- Power BI charts, KPI cards, and slicers

## Files
- `Task_4_Sales_Dashboard.pbix` - Power BI dashboard
- `Task_4_Sales_Dashboard_Final.pptx` - Dashboard summary presentation
- Dashboard screenshot - Visual proof of the completed dashboard

## Purpose
The dashboard provides an interactive view of sales performance and helps stakeholders compare revenue across countries and time periods.
